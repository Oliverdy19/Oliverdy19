Analista senior en Inteligencia Comercial dentro del sector de telecomunicaciones. Convierto datos en decisiones de negocio mediante análisis de clientes, análisis geoespacial y visualización de datos.

## Áreas de especialización

- **Divulgación:** publico contenido semanal sobre Data Analytics.
